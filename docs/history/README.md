# History

Records of how the first version of the package was built, in October 2026,
by one researcher on one machine: the original design and plan, the test
logs of each wave of skills, and the plan of the pass that made the package
general.

They are kept because they say what was verified and what was not. They are
superseded as design documents by `../specs/` and `../plans/`.

Machine paths were replaced by placeholders: `<repo>` is this repository,
`<skills>` its `skills/` directory, `<docs>` the directory these files lived
in, `<config>` and `<packages>` the builder's private configuration and code
directories, `<scratch>` a temporary directory. The skills these logs name
`observational-cosmology/references/pv-surveys.md` and
`fsigma8-pv-compilation.md` now live in `cosmo-peculiar-velocities`.
