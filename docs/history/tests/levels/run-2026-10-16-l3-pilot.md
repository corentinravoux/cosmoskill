# Level test — L3 pilot of 2026-10-16

Roadmap work package 4.4 (`docs/plans/2026-10-12-cosmoskill2-roadmap.md`,
Phase 4), on the two pilot skills that have level-3 dossiers:
`cosmo-galaxy-clustering` and `cosmo-statistics-inference`. The 24 questions
are in `docs/tests/levels/l3-questions.md`. Each was answered twice from the
skill files only: an **L2 run** (the skill's `SKILL.md` plus one reference
file chosen from the file map) and an **L3 run** (the same plus at most one
dossier of `deep/`, chosen from the file map). Model memory was not used to
fill gaps; where the allowed files do not answer, the answer says so. This
run tests; no skill file was changed.

## Procedure

1. **Questions first.** The questions were written from the two
   `references/subtopics.tsv` files and the roadmap's description of L3,
   before either `SKILL.md` or any dossier was opened. The session was cut by
   its limit after the questions file was written and was resumed; the
   resumed session checked that the file holds 24 questions and did not
   change it.
2. **Preliminaries.** Read: the earlier level tests (`questions.md`,
   `questions-recheck.md`, `expected.md`, the 2026-10-12 recheck run), the
   level table of `skills/observational-cosmology/SKILL.md` ("Choosing the
   level"), roadmap Phase 4. Layer check: no `.cosmoskill/` in the working
   directory, its parents or the home directory; `COSMOSKILL_HOME` unset;
   layer `base` for every question.
3. **Files read.** Both `SKILL.md` files in full. Galaxy clustering:
   `references/physics-and-methods.md` and `references/systematics.md` in
   full; the three dossiers in full. Statistics: `references/physics-and-methods.md`
   Sects. 1–2, 5–9 and 12; the three dossiers in full. No other reference
   file of either skill was opened.
4. **Isolation.** One session answered all questions, so each file was read
   once and the answer to each question was then restricted to the passages
   of the file assigned to that run. This is weaker than a fresh session per
   run: an L2 answer could in principle be coloured by a dossier read later.
   To limit this, every L2 grade below names the passage it rests on.
5. **Grading.** (a) Y answers the question, P partly, N not; (b) locator:
   Y when the answer carries paper + section, table or equation for its
   load-bearing statements; (c) suspected errors, checked at source with
   `fetch_paper.py` (15 checks, the cap).
6. **Reading of acceptance (a).** "The L3 run answers" counts Y only.
   "The L2 run failed" counts P and N. Under the stricter reading (N only)
   the counts are given as well.

## Answers, cosmo-galaxy-clustering

**G1 — RecIso against RecSym.**
- L2: DESI DR1 and DR2 use RecSym (randoms shifted with the same
  redshift-space displacement, linear RSD kept), BOSS/eBOSS used RecIso
  (arXiv:2404.03000, Sect. 4.2, Table 4); in the template s(k) = 0 for RecSym
  (Eq. 9). What the choice does to the damping is not in the file.
- L3: adds the linear predictions of both conventions (arXiv:2402.14070,
  Sect. 4.1), the single-exponential damping for RecSym against the piecewise
  Σ_ss, Σ_ds damping for RecIso (Eqs. 26–27), the conclusion that RecIso keeps
  part of the shift and is more damped and more sensitive (Sect. 4.2.2),
  solver sensitivity (arXiv:2411.19738, Sect. 8), Euclid's recommendation of
  RecSym (arXiv:2605.03446, Sect. 7).

**G2 — BAO template, broadband, damping priors.**
- L2: the full DR1 template (arXiv:2404.03000, Eqs. 5–16, Tables 5–6): only
  the wiggle term dilated, spline broadband of width 2π/r_d replacing
  polynomials, Gaussian priors σ = 1, 2, 2 h⁻¹ Mpc on Σ_⊥, Σ_∥, Σ_s with
  post-reconstruction centres. Why the spline was chosen is not stated.
- L3: adds the reason for the damping priors (about 20% of expected values;
  fixed values bias α, free values give weak, biased fits;
  arXiv:2402.14070, Sect. 7.8), FoG on the smooth part only, the de-wiggling
  choice, and the competing eBOSS and Euclid broadbands. Why the spline was
  preferred is still not stated: the dossier lists it among Chen et al.'s
  eight changes without the authors' reason (see check C3).

**G3 — BAO systematic budget.**
- L2: per-term DR1 table with method and size (theory 0.1/0.2%, HOD 0.2%,
  fiducial 0.1%, total 0.245% and 0.3%, worst case over tracers, quadrature,
  C_sys added to each bin, about 5% on the error; arXiv:2404.03000,
  Sect. 5.5, Tables 12–13), the DR2 per-tracer table and inflation of 1–9%
  (arXiv:2503.14742, Table 5; arXiv:2503.14738, Sect. III.1), detection rules.
- L3: adds the 3σ detection threshold and the ten-item DR2 unblinding list
  (arXiv:2503.14742, Sect. VI.2, Table 6). L2 already answered.

**G4 — Full modelling against ShapeFit.**
- L2: parameters of each route (methods Sect. 3 table), DESI DR1 chose full
  modelling because projection effects bias compressed parameters in weak
  bins (arXiv:2411.12021), the 2026 analysis chose ShapeFit to remove
  prior-volume effects (arXiv:2602.18761). What compression loses and when the
  two agree: not in the file.
- L3: adds what ShapeFit misses (BAO amplitude, ω_b without BBN;
  arXiv:2106.07641, Sect. 7; arXiv:2404.07283, Sect. 3.3), same-data shifts
  of about 0.5σ (ΛCDM) and ≤ 0.7σ (wCDM) (arXiv:2404.07283, Sect. 8), the
  condition under which template and direct fits coincide (tight priors on
  the other ΛCDM parameters and on α̃, ε; arXiv:2302.07430, Sect. 5), and the
  opposing DR1 and 2026 readings.

**G5 — k_max choice and validation.**
- L2: DESI DR1 uses 0.02 < k < 0.20 h Mpc⁻¹; k_min set by the imaging
  correction; moving k_max changes neither peak nor errors
  (arXiv:2411.12021, Sect. 4.7). Which mocks and which bias criterion: not in
  the file.
- L3: adds the table of k_max with the validation of each analysis (BOSS
  East coast 0.25 with residual model error plus projection ≤ 1σ,
  arXiv:1909.05277; West coast 0.23 with σ_sys from Challenge boxes,

  arXiv:2404.07283, Sect. 8), code divergence above ≈ 0.26 at large volume

  full-survey covariance).

**G6 — Counterterm and stochastic priors; projection effects.**

## Answers, cosmo-statistics-inference

All L2 runs used `references/physics-and-methods.md`.

**S1 — Hartlap or Sellentin–Heavens.**
- L2: Hartlap unbiases the precision, not the interval (arXiv:astro-ph/0608064,
  Sect. 3.1); SH marginalises Σ with a Jeffreys prior and gives a
  t-distribution (arXiv:1511.05969, Eqs. 6, 12–13); same covariance hS,
  heavier tails, matters for data in tension; SH lacks the DS term;
  Percival 2022 matching prior and its Gaussian approximation S′
  (arXiv:2108.10402). Y.
- L3: adds the rule "never Hartlap with the t-distribution" (arXiv:2606.18446;
  arXiv:2108.10402, Sect. 7) and the coverage test (Sect. 6). Y.

  realisations for 5% on an error with N_D ≪ 100 (arXiv:1212.4359). Y.
- L3: adds which of the three corrections applies to which error, with m_2

## Recommendations for the dossier brief (`docs/agent-brief-l3.md`)

1. **Give the authors' reason for each choice, with its locator.** The
   "Choices and what they cost" tables list what each pipeline does but can
   drop why it does it: the spline broadband appears as one of eight DESI
   changes while its source section gives the reason in one sentence (C3),
   and G2 stayed partial at L3 for that alone. Add a mandatory "reason
   given by the authors" entry per choice, or "none given".
2. **Define every symbol and every aggregate where it is used.** Two
   correct statements read as wrong: a formula whose P_shot is
   dimensionless without saying so (C2), and bin volumes listed next to a
   total they do not add to because the bins overlap (C1). A number that
   differs from an L2 number for the same quantity must say why (C3/C15:
   14 + 7 against 25 broadband-plus-physical parameters). A significance a
   source computes as √Δχ² for several parameters should carry a one-line
   note (C12).
3. **Write each dossier against an L2 gap audit, and define the target
   band per domain.** Run the subtopic's questions at L2 before the dossier
   brief is issued, and aim the dossier at what fails. In
   `cosmo-statistics-inference` the L2 methods file already holds the
   formulae, conditions and interpretation for six of eight dossier
   questions, so the dossiers should concentrate on procedures, validation
   recipes, pass criteria and head-to-head choices (what passed S3 and S4)
   — or the brief should move derivation-level material from L2 into the
   dossiers. Record in `subtopics.tsv` (`files` column) when a dossier also
   serves another subtopic, as `estimators-window` does for
   `primordial-non-gaussianity` (G11). The acceptance clause on L2 failures
   should count partial answers, since no L2 answer was an outright N.
